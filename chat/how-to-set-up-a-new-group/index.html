How to set up a new WhatsApp group properly

The first ten minutes decide what kind of group it will be. Set these things up before you add the first twenty people, and you will not have to fix them in the middle of an argument later.

Checklist

  1. Choose a clear name. People should know what the group is from the name alone. See group name ideas or try the name maker.
  2. Add a photo that belongs to the group: the society gate, a family photo that everyone has agreed to, the team logo.
  3. Write the description. One or two lines on the purpose and the main rule. Ready texts are on the descriptions page.
  4. Set the permissions. In the group's settings, admins can decide whether all members or only admins may change the group's name and photo, send messages and add other members. For large or public groups, let only admins edit the group information.
  5. Decide how people join. For a private group, add people yourself. If you share an invite link, turn on admin approval for new members, and reset the link if it spreads too far.
  6. Name a second admin.
  7. Post and pin the rules. Use a ready set from group rules.
  8. Send a welcome message that asks people to introduce themselves. See welcome messages.
  9. Ask before adding. Not everyone wants to be in every group. A one-line private message, "May I add you to the class group?", is good manners.
  10. Start the first conversation. A simple poll or an icebreaker question gets the first replies.

Group or community?

WhatsApp also has communities, which bring several related groups, for example all the blocks of one society or all the sections of one class, under one announcement channel. If you find yourself posting the same notice in five groups, a community may suit you better.

This site is independent and is not connected with WhatsApp. Menu names in the app change from time to time; the settings described here were checked in November 2026. For the exact steps on your phone, see the WhatsApp Help Centre at faq.whatsapp.com.
