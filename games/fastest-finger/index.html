Fastest Finger First

One question at a time, and only the first right reply scores. It is the liveliest way to run a quiz in a small, active group.

Players
3 or more
Time
10 minutes
You need
Questions ready
Ages
8 and above
Type
WhatsApp group games

Who it suits and when to play

Fastest Finger First suits quiz-loving groups and families with school children, from about eight. It is quick, loud and competitive, so it wakes up a sleepy group. Because speed decides the winner, slow networks and slow typists lose out; balance that with the fixes below. Prepare the questions and answers before you start.

How to play

  1. Tell the group the time of the game and the number of questions.
  2. Post one question. Do not give options, so that members have to type the answer.
  3. The first correct reply gets the point. WhatsApp shows the order of messages, so there are no arguments.
  4. If nobody answers in one minute, give the answer and move on.
  5. Keep the score on paper or on a scoreboard, and post it after every five questions.

Ready message to start the game

Fastest finger first! 10 questions. Only the FIRST right answer gets the point. No searching, please. Question 1 is coming...

Tips and variations

  • Ready rounds with checked answers are on our sister site, quiz.shareyourgroup.com.
  • Slow typists lose in this game. Mix it with a round where everybody answers in three minutes.

Common problems and how to fix them

  • A slow phone or network loses to a fast one. Give points to the first three right answers, not only the first.
  • An answer is disputed. The host checks before the game that every question has one clear answer, and skips any that are doubtful.
  • Players search for answers online. Keep the time to ten seconds, or use questions about the group itself, which no search can answer.
